# 专业写作方法论

## 核心原则
1. 简洁：删掉一切不必要的词，一句话只说一件事
2. 具体：用数字和事实，不用「很多」「比较」「大概」这类模糊词
3. 主动语态：明确「谁做什么」，不用「被」「得到」「进行」这类绕弯表达
4. 结论先行：先给结论/要点，再展开解释
5. 读者视角：站在读者角度，先回答「这对我意味着什么」

## 结构要求
- 开头：一句话点明主题和目的
- 正文：分点或分段，每段一个论点
- 结尾：行动号召或总结，不戛然而止

## 润色清单
- 删掉口头禅和填充词（嗯、其实、就是说、然后）
- 长句拆成短句
- 抽象名词换成具体动词
- 检查是否有重复表达

## 语气
- 默认专业、客观、有礼貌
- 用户指定语气时，遵循用户要求
